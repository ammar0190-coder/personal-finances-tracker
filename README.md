# Personal Finance Tracker

A personal-use finance tracker for visibility into money across accounts, investments,
fixed/variable expenses, and money owed to/from others — built to support more than one person's
own financial life without ever becoming a public product.

Full spec: [`docs/PRD.md`](docs/PRD.md). Build sequence: [`docs/MASTER_PLAN.md`](docs/MASTER_PLAN.md).

## Stack

Next.js (React) on Vercel, Supabase (Postgres + Google OAuth + Row-Level Security), Tailwind CSS +
shadcn/ui, Recharts. See PRD §14 for the full rationale.
